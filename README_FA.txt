چالش دانا — نسخه تصویری و گسترده

ویژگی‌های این نسخه:
- بیش از ۱۰۰۰ سؤال دانستنی در دسته‌های مختلف
- سؤال‌ها محدود به ۵ سؤال نیستند و بعد از هر پاسخ سؤال بعدی نمایش داده می‌شود
- هر سؤال دارای تصویر/تصویرسازی موضوعی است
- پس‌زمینه در مراحل مختلف تغییر می‌کند
- نمایش واضح پاسخ‌های چهارگزینه‌ای
- بعد از پاسخ، جواب درست و امتیاز مشخص می‌شود و سپس با مکث کوتاه سؤال بعدی می‌آید
- امتیاز و سکه
- راست‌چین و مناسب فارسی
- آیکون جدید و شیک برای برنامه

این نسخه برای ادامه توسعه در GitHub آماده شده است.
برای ساخت APK، پروژه را در مخزن GitHub قرار دهید و Workflow موجود در .github/workflows/build-apk.yml را اجرا کنید.
