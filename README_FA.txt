چالش دانا - نسخه اصلاح‌شده

تغییرات این نسخه:
- صفحه اصلی فقط دکمه «شروع چالش» را دارد؛ کارت درود و دکمه‌های اضافی حذف شدند.
- نام و عکس کاربر فقط از آیکون پروفایل بالای صفحه قابل تنظیم است.
- تنظیمات کنار پروفایل در نوار بالایی قرار گرفت.
- نمایش سکه به شکل «🪙 ۵۰ سکه» و بدون مربع اضافی.
- نوار خانه، رتبه‌ها، علاقه‌مندی‌ها و پروفایل در پایین صفحه قرار گرفت.
- پس‌زمینه تخت‌جمشید/فروهر بدون تاری و بدون عناصر اسکرین‌شات استفاده شد.
- اندازه‌ها برای موبایل کوچک‌تر و خواناتر تنظیم شدند.
- حاشیه بیرونی آیکون چالش دانا حذف و آیکون متعادل‌تر شد.
- چندین سؤال زبان انگلیسی به‌صورت مستقیم داخل بانک سؤال‌ها اضافه شد؛ منوی جداگانه انگلیسی وجود ندارد.
- پروژه برای Android SDK 35 و Java 17 تنظیم شده است.
