چلنج دانا - نسخه اصلاح‌شده

تغییرات این نسخه:
- صفحه اصلی کاملاً ثابت است و اسکرول/حرکت ندارد.
- دکمه «شروع چالش» در مرکز صفحه قرار گرفته است.
- منوی خانه، رتبه‌ها، علاقه‌مندی‌ها و پروفایل پایین صفحه قرار دارد.
- کادر مربع کنار سکه حذف شده و فقط نمایش سکه باقی مانده است.
- تصویر پروفایل به صورت دایره‌ای برش می‌خورد و کادر دایره‌ای اضافه ندارد.
- شمارنده جان‌ها بدون آیکون قلب نمایش داده می‌شود.
- سؤال‌های انگلیسی پشت سر هم نیستند: هر ۱۰ سؤال عمومی، ۱ سؤال انگلیسی می‌آید.
- ترتیب سؤال‌های ۱۰+۱ هنگام شروع بازی دوباره به‌هم نمی‌ریزد.
- مجموعه سؤال‌های انگلیسی شامل ۵۰۰ سؤال تولیدشده با سطح متنوع است.
